# keepgoing.dev Site Split Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Move `site/` out of the Momentum Mascot repository into `keepgoing-dev/keepgoing.dev`, turn the root into a two-product hub, and serve the mascot page at `/momentum-mascot`, without breaking the URLs that shipped binaries and App Store Connect already depend on.

**Architecture:** A static site, no build step, as today. The work is a repository extraction that preserves history, a path-resolution fix that must land before anything moves, three pages (hub, mascot, Commitropolis teaser), and a Cloudflare Pages cutover gated on a verification script that is written first and run at every stage.

**Tech Stack:** Static HTML and CSS. `git subtree split` for extraction. Cloudflare Pages for hosting. `curl` and `grep` for verification. No framework, no bundler, no dependencies.

**Spec:** `docs/superpowers/specs/2026-09-13-keepgoing-dev-site-split-design.md`

## Global Constraints

- **`keepgoing.dev/#support` must resolve on the root page forever.** `src-tauri/src/tray.rs:22` compiles this URL into every shipped binary, App Store builds included. It cannot be changed retroactively. Breaking it breaks the Support menu item for existing users and nothing reports the failure.
- **`/privacy` must stay at exactly that path.** It is registered with App Store Connect (`docs/app-store-listing.md:333`).
- **Verify by content, never by status code.** The domain serves a page for unknown paths (`docs/app-store-listing.md:336`), so a 200 proves nothing.
- **Composited art only.** Per `docs/app-store-licence-check.md:98`, the public site may carry composited rooms and cards and never layers or swatches. This is what makes a public site repository compatible with LimeZu's licence.
- **The site cannot rebuild its own images.** Every GIF and PNG is generated by tools in the mascot repository that need a licensed `$MASCOT_PACK`. The site repository holds the output as committed files.
- **The root page returns 200 with new content.** It does not redirect. The old root and the new root are both real pages, just different ones.
- **No em dashes** in any copy, per the repository's house style. Use a hyphen or rewrite.

**Paths in this plan** are relative to the new `keepgoing.dev` repository once Task 1 has run, except where a path is explicitly prefixed `momentum-mascot/`, which means the Momentum Mascot repository.

### Task 2: Write the verification script before building anything

**Files:**
- Create: `tools/verify-site.sh`

**Interfaces:**
- Consumes: nothing.
- Produces: `tools/verify-site.sh [base-url]`. With no argument it checks the local working tree as files. With a URL it checks a deployed site over HTTP. Exits non-zero on any failure. Every later task runs it.

This is the failing test. It encodes the three checks from the spec plus the path-resolution check that Task 3 exists to satisfy, and it will fail on almost everything until the later tasks land. That is the point: run it now, watch it fail, and know exactly what "done" means.

- [ ] **Step 1: Write the script**

```bash
#!/usr/bin/env bash
# Checks the invariants in docs/superpowers/specs/2026-09-13-keepgoing-dev-site-split-design.md
set -uo pipefail

BASE="${1:-}"
fails=0

ok()   { printf '  ok    %s\n' "$1"; }
fail() { printf '  FAIL  %s\n' "$1"; fails=$((fails + 1)); }

# Fetch a path as text, from the network or from disk.
get() {
  local path="$1"
  if [ -n "$BASE" ]; then
    curl -fsS "${BASE}${path}" 2>/dev/null
  else
    case "$path" in
      /)                  cat index.html ;;
      /privacy)           cat privacy.html ;;
      /momentum-mascot)   cat momentum-mascot/index.html ;;
      /commitropolis)     cat commitropolis/index.html ;;
      *)                  cat ".${path}" ;;
    esac 2>/dev/null
  fi
}

echo "Pinned URLs"

# The App Store's registered Privacy Policy URL. Checked by content because the
# domain serves a page for unknown paths, so a status code proves nothing.
if get /privacy | grep -q "<title>Privacy Policy"; then
  ok "/privacy serves the privacy policy"
else
  fail "/privacy does not serve the privacy policy"
fi

# Compiled into every shipped binary as the Support menu item. Nothing in the
# app reports this being broken, which is why it is checked here.
if get / | grep -q 'id="support"'; then
  ok "/ carries #support"
else
  fail "/ is missing #support, which breaks Support in every shipped build"
fi

if get /momentum-mascot | grep -q 'id="support"'; then
  ok "/momentum-mascot carries #support"
else
  fail "/momentum-mascot is missing #support"
fi

echo "Pages"
for path in / /momentum-mascot /commitropolis /privacy; do
  if get "$path" | grep -q "</html>"; then
    ok "$path serves a complete page"
  else
    fail "$path does not serve a complete page"
  fi
done

echo "Path resolution"

# Relative src/href in HTML resolves against the page URL, so a page served at
# /momentum-mascot/ would look for /momentum-mascot/assets/. Root-absolute only.
if [ -z "$BASE" ]; then
  rel=$(grep -rnoE '(src|href)="[^"]+"' --include="*.html" --exclude-dir=.git . 2>/dev/null \
          | grep -vE '="(/|https?:|mailto:|#)' || true)
  if [ -n "$rel" ]; then
    printf '%s\n' "$rel"
    fail "relative src/href found in HTML; assets will 404 under a subpath"
  else
    ok "all HTML src/href are absolute"
  fi

  # Captured, not piped. grep exits 2 when a listed file is missing and `set -o pipefail`
  # propagates that, so a status test would report "pass" while matches existed.
  hits=$(grep -hnE 'assetDir: *"[^/]' index.html momentum-mascot/index.html 2>/dev/null || true)
  if [ -n "$hits" ]; then
    printf '%s\n' "$hits"
    fail "relative assetDir in the preloader script"
  else
    ok "preloader assetDir paths are absolute"
  fi
fi

echo "Licence"

# docs/app-store-licence-check.md: composited rooms and cards only, never
# layers or swatches. This is what makes a public site repository lawful.
if [ -z "$BASE" ]; then
  if find . -path ./.git -prune -o -type f \
       \( -name "*layer*" -o -name "*strip*" -o -name "*swatch*" -o -name "*plate*" \) -print \
       | grep -q .; then
    fail "layer, strip, swatch or plate files present; the licence forbids publishing these"
  else
    ok "no layer or swatch files"
  fi
fi

echo
if [ "$fails" -eq 0 ]; then
  echo "PASS"
else
  echo "FAIL: $fails check(s)"
fi
exit $((fails > 0))
```

### Task 3: Make every asset reference root-absolute

**Files:**
- Modify: `index.html` (lines 27, 30, 34, 67, 139, and the `assetDir` values in the script at 250)
- Modify: `404.html` (lines 9, 13, 20)
- Modify: `privacy.html` (line 9)
- Modify: `style.css` (every `url("assets/...")`)

**Interfaces:**
- Consumes: `tools/verify-site.sh` from Task 2.
- Produces: a tree where no HTML, CSS or JS reference depends on the page's own URL depth. This is what makes Task 4 safe.

This lands before anything moves. A relative `src="assets/logo.png"` on a page served at `/momentum-mascot/` resolves to `/momentum-mascot/assets/logo.png` and 404s. The page still renders and the art silently disappears, which is the worst kind of failure: it looks like a styling problem days later.

CSS is a separate case. `url("assets/...")` in a stylesheet resolves against the **stylesheet's** URL, not the page's, so it happens to work today. It is fixed anyway so that `style.css` can move later without a second silent breakage.

- [ ] **Step 1: Run the failing check in isolation**

```bash
grep -rnoE '(src|href)="[^"]+"' --include="*.html" --exclude-dir=.git . \
  | grep -vE '="(/|https?:|mailto:|#)'
```

Two stages rather than a negative lookahead, because BSD `grep` on macOS has no `-P`.

Expected: nine hits, verified against the tree as it stands. A leading `./` on each path may
or may not be present depending on whether `grep` is BSD's or a drop-in replacement, so match on
the file and line rather than the exact prefix.

```

404.html:13:href="assets/logo.png"
404.html:20:src="assets/logo.png"
index.html:27:href="assets/logo.png"

index.html:34:href="assets/logo.png"
```
